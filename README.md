# Blog Auth - Module 5

JWT authentication (httpOnly cookie), protected routes, user dashboard showing only the logged-in user's blogs, profile page and logout.

## Stack
React (Vite), Node, Express, MongoDB (Mongoose)

## Setup
1. `cd server && npm install`
2. Create `server/.env` with: PORT, MONGO_URI, JWT_SECRET, CLIENT_URL
3. `node server.js`
4. `cd client && npm install && npm run dev`
5. Open http://localhost:5173
